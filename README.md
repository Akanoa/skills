# skills

Skills for Claude Code.

| Skill | What it does |
|---|---|
| [mbx](mbx/SKILL.md) | Build, test and diagnose Rust projects with mbx, a caching wrapper around Cargo |

## Install

Copy a skill's folder into `~/.claude/skills/`:

```sh
git clone git@github.com:Akanoa/skills.git
cp -r skills/mbx ~/.claude/skills/
```
